# Checklist generală Scut Digital

Această checklist te ajută să verifici rapid dacă viața ta digitală este protejată.

Folosește această listă o dată pe lună sau de fiecare dată când simți că un cont poate fi în pericol.

## 1. Email principal

[ ] Folosesc o parolă unică pentru email

[ ] Parola nu este folosită pe alte site-uri

[ ] Autentificarea în doi pași este activată

[ ] Numărul de telefon de recuperare este corect

[ ] Emailul de recuperare este corect

[ ] Am verificat dispozitivele conectate

[ ] Am eliminat dispozitivele necunoscute

[ ] Am verificat redirecționările suspecte

[ ] Am verificat filtrele suspecte

## 2. Parole

[ ] Fiecare cont important are parolă diferită

[ ] Nu folosesc parole simple

[ ] Nu folosesc data nașterii ca parolă

[ ] Nu folosesc același cuvânt peste tot

[ ] Folosesc un manager de parole

[ ] Nu salvez parolele în WhatsApp, Messenger sau poze

[ ] Nu trimit parole prin mesaje

[ ] Nu spun parolele altor persoane

## 3. Autentificare în doi pași

[ ] 2FA este activ pe email

[ ] 2FA este activ pe Facebook

[ ] 2FA este activ pe TikTok

[ ] 2FA este activ pe Instagram

[ ] 2FA este activ pe YouTube

[ ] 2FA este activ pe conturile bancare

[ ] 2FA este activ pe PayPal sau Stripe, dacă le folosesc

[ ] Am salvat codurile de rezervă într-un loc sigur

[ ] Nu trimit codurile de verificare nimănui

## 4. Social media

[ ] Am verificat dispozitivele conectate

[ ] Am verificat aplicațiile conectate

[ ] Am eliminat aplicațiile necunoscute

[ ] Am verificat emailul conectat la cont

[ ] Am verificat numărul de telefon conectat

[ ] Am verificat persoanele care au acces la pagini

[ ] Nu folosesc servicii de urmăritori falși

[ ] Nu apăs pe linkuri primite în mesaje suspecte

[ ] Nu trimit coduri de verificare prin chat

## 5. Telefon

[ ] Telefonul are blocare activă

[ ] Nu folosesc cod PIN simplu

[ ] Sistemul este actualizat

[ ] Aplicațiile sunt actualizate

[ ] Aplicațiile sunt instalate doar din surse oficiale

[ ] Am verificat permisiunile aplicațiilor

[ ] Am eliminat aplicațiile pe care nu le folosesc

[ ] Am activat localizarea telefonului

[ ] Am backup pentru poze și documente importante

## 6. Calculator

[ ] Sistemul este actualizat

[ ] Browserul este actualizat

[ ] Antivirusul este activ

[ ] Nu deschid fișiere suspecte

[ ] Nu descarc programe de pe site-uri necunoscute

[ ] Am verificat extensiile din browser

[ ] Am eliminat extensiile necunoscute

[ ] Nu folosesc calculatorul infectat pentru conturi bancare

[ ] Am backup pentru fișiere importante

## 7. Website și proiecte online

[ ] Website-ul este actualizat

[ ] Tema este actualizată

[ ] Pluginurile sunt actualizate

[ ] Pluginurile nefolosite sunt șterse

[ ] Există backup pentru website

[ ] Domeniul este protejat

[ ] Hostingul este protejat

[ ] Emailul conectat la hosting este sigur

[ ] Nu există utilizatori administrator necunoscuți

[ ] Parola de administrator este puternică

## 8. Afaceri mici și colaboratori

[ ] Am o listă cu toate conturile importante

[ ] Știu cine are acces la fiecare cont

[ ] Colaboratorii au doar accesul necesar

[ ] Am eliminat accesul persoanelor inactive

[ ] Conturile de plată sunt protejate

[ ] Facturile sunt verificate înainte de plată

[ ] Datele clienților sunt protejate

[ ] Documentele importante sunt salvate în siguranță

[ ] Backup-ul este verificat periodic

## 9. Phishing și mesaje suspecte

[ ] Verific adresa expeditorului

[ ] Nu apăs pe linkuri suspecte

[ ] Nu introduc parola pe pagini primite prin mesaj

[ ] Nu trimit coduri de verificare

[ ] Verific mesajele urgente înainte să acționez

[ ] Nu descarc fișiere necunoscute

[ ] Verific direct în aplicația oficială

[ ] Nu am încredere în mesaje care promit bani rapizi

[ ] Nu am încredere în mesaje care amenință suspendarea contului

## 10. Backup

[ ] Am backup pentru poze importante

[ ] Am backup pentru documente personale

[ ] Am backup pentru fișiere de muncă

[ ] Am backup pentru website

[ ] Am backup pentru proiecte importante

[ ] Am o copie în cloud

[ ] Am o copie pe dispozitiv extern

[ ] Am verificat dacă backup-ul poate fi restaurat

## 11. Plan de urgență

[ ] Știu care este emailul meu principal

[ ] Știu unde se schimbă parola emailului

[ ] Știu unde verific dispozitivele conectate

[ ] Știu cum blochez telefonul pierdut

[ ] Știu cum recuperez conturile social media

[ ] Știu cum contactez banca

[ ] Știu cum contactez hostingul

[ ] Am o listă cu serviciile importante

[ ] Nu țin parolele în lista de urgență

## 12. Verificare rapidă lunară

O dată pe lună verifică:

[ ] Emailul principal

[ ] Parolele importante

[ ] Autentificarea în doi pași

[ ] Dispozitivele conectate

[ ] Social media

[ ] Telefonul

[ ] Calculatorul

[ ] Website-ul

[ ] Backup-ul

[ ] Conturile de plată

## Scor personal

Calculează câte puncte ai bifat.

Dacă ai sub 30 de puncte bifate, securitatea ta este slabă.

Dacă ai între 30 și 60 de puncte bifate, securitatea ta este medie.

Dacă ai peste 60 de puncte bifate, securitatea ta este bună.

Important: checklistul nu garantează protecție totală, dar reduce mult riscurile.

## Regula de aur

Cel mai important cont este emailul principal.

Dacă emailul principal este protejat, poți recupera mai ușor restul conturilor.

## Recomandare finală

Nu încerca să faci totul într-o singură zi.

Alege 5 puncte din checklist și rezolvă-le azi.

Mâine mai rezolvă 5.

În câteva zile, securitatea ta digitală va fi mult mai bună.
